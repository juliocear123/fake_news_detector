# 🚀 Fake News Detector AI

### 🤖 Inteligência Artificial aplicada à análise de notícias em tempo real

Projeto desenvolvido para feiras científicas, apresentações tecnológicas e demonstrações de Inteligência Artificial Generativa aplicada à análise contextual de notícias.

---

## 📌 Sobre o Projeto

O **Fake News Detector AI** é uma aplicação web capaz de analisar textos jornalísticos e identificar a probabilidade de uma notícia ser verdadeira ou falsa utilizando Inteligência Artificial.

Diferente de modelos tradicionais baseados apenas em Machine Learning, este sistema utiliza modelos avançados de linguagem para realizar:

✅ Análise contextual

✅ Interpretação semântica

✅ Verificação de plausibilidade

✅ Processamento de Linguagem Natural (NLP)

✅ Explicações automáticas dos resultados

---

## 🎯 Objetivos

- Demonstrar aplicações práticas de IA Generativa;
- Integrar Front-end, Back-end e Inteligência Artificial;
- Desenvolver uma API REST utilizando Flask;
- Trabalhar com análise textual em tempo real;
- Simular um sistema moderno de detecção de Fake News;
- Apresentar conceitos de Engenharia de Prompt e NLP.

## 🧠 Como Funciona

```text
Usuário digita uma notícia
          ↓
Front-end envia o texto para a API Flask
          ↓
Flask processa a requisição
          ↓
GPT-4o analisa o contexto da informação
          ↓
Sistema gera o resultado
          ↓
Exibe:
- Probabilidade de ser verdadeira
- Probabilidade de ser falsa
- Explicação automática
```
